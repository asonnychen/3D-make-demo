# 3D台球 · 九号俱乐部 CLUB No.9

用 Three.js + Rapier 制作的第一人称 3D 台球练习场。灯亮着，球摆好了，鼠标就是你的球杆。

- 渲染：Three.js 0.187
- 物理：Rapier 3D（`@dimforge/rapier3d-compat` 0.21），120 Hz 固定步长
- 构建：Vite 8 + Tailwind CSS 4
- 端口：5181

## 运行

在仓库根目录执行（依赖由根 `package.json` 统一管理）：

```powershell
pnpm install
pnpm dev:billiards    # http://127.0.0.1:5181
pnpm build:billiards  # 构建到 3D台球/dist/
```

## 玩法

自由练习模式，不计犯规、不限杆数。按住左键蓄力，松开出杆；白球落袋后会自动摆回开球点，目标球落袋后留在袋里。清台后按 R 重新摆球，或打开逐杆回放研究走位。

## 操作

| 输入 | 作用 |
| :--- | :--- |
| 移动鼠标 | 站在球杆后方，旋转球杆与视角 |
| 按住鼠标左键 | 蓄力（底部力度条 0–100%） |
| 松开鼠标左键 | 出杆，力度越大球速越快 |
| `R` | 重新摆球（清空台面、重置杆数） |
| `L` | 打开 / 关闭逐杆回放列表 |
| `M` | 静音 / 恢复音效 |
| `H` | 打开操作指南 |
| `Esc` | 暂停 |

开始游戏后镜头位于球杆后方并与瞄准方向对齐；移动鼠标旋转球杆/视角。浏览器会请求锁定鼠标，按 `Esc` 暂停，点「继续游戏」重新锁定；锁定失败时仍可用普通鼠标移动瞄准。

## 已实现

- **第一人称瞄准**：镜头在球杆正后方，沿球杆和瞄准方向对齐；移动鼠标转动视野与球杆，台面投影虚线、幽灵球、目标球分离方向都保持在视线中。
- **蓄力出杆**：按住左键蓄力，球杆后拉，力度条绿→金→红；松开按力度给白球线速度与少量前旋。
- **真实碰撞与落袋**：Rapier 刚体球、六段库边、袋口判定、球球/球库碰撞音效；落袋有下沉动画，白球落袋自动回到开球点（避开其他球）。
- **自由练习**：十五颗目标球标准三角摆球，杆数 / 已进球 / 剩余球计数，落袋球在左上角列出，清台提示。
- **逐杆回放**：每一杆记录 60 Hz 球位与四元数，最多保留最近 8 杆；回放面板可查看杆数、进球数、时长，支持播放 / 暂停 / 拖动进度 / 重播，回放时自动切到俯视机位。
- **中英文切换**：界面文案、操作指南、设置、回放、暂停菜单全部实时切换，语言写入 `localStorage`。
- **设置**：鼠标灵敏度、音量、细腻 / 流畅画质（关闭阴影并降低像素比），设置持久化。
- **程序化场景**：木纹房间、波斯地毯、画框、飞镖盘、吊灯、暗铜袋口、台呢噪点与号码球贴图全部由 Canvas 与几何体生成，没有外部模型 / 贴图 / 音频。

## 实现要点

- 台面按英式十二尺大台建模：3.57 m × 1.78 m，球半径 28.575 mm，球质量 0.17 kg。
- 绿色台边与台呢使用同一材质并在台面同一高度，形成一圈几乎齐平的窄绿边；木框内沿压住绿边约 1.8 cm，并带象牙菱形瞄点；袋口向库边靠拢并缩小到约 9 cm 直径，木框为整块挤出，中袋与四个角袋都以圆弧向内收口，连续无拼缝，袋口与铜环完整露出，木框顶面仅比台面高约 4 cm。
- 物理以 `1/120 s` 固定步长推进，最多补 8 步，避免掉帧时穿模；球体开启 CCD。
- 库边碰撞体按袋口位置留出缺口；落袋判定与可见袋口同半径，并采用线段扫掠，高速球也不会跳过。缺口两侧有隐形导向颚，球不会从缝隙滚出桌面；另有台面边界兜底，越界球会被拉回。
- 木框内沿压进绿边 1.8 cm、袋口贴花抬高到台呢上方 3 mm，避免共面几何在镜头移动时产生 Z-fighting 闪烁；阴影贴图 2048、normalBias 0.02 进一步压制台呢阴影抖动。
- 回放只记录位移与旋转，回放相机固定俯视，退出后从物理刚体恢复实时球位，互不污染。
- 所有音效由 Web Audio 振荡器与噪声缓冲实时合成，首次「开始游戏」时解锁音频上下文。

## 已知限制

- 面向桌面键鼠设计，不提供触屏摇杆；手机端可打开页面，但没有完整操作方式。
- 自由练习模式，不含九球 / 八球完整规则、犯规判定、AI 对手或联网对战。
- 回放仅保留最近 8 杆，刷新页面后清空。
