# 我的世界 · Mine World

用 **PlayCanvas 2.x** 复现的《我的世界》体素沙盒：一片程序化生成的方块岛屿，可以第一人称走过去、挖开它、再把它重新盖起来。地形、树木、方块贴图、天空与云层全部在浏览器里实时生成 —— 没有 `.glb`、没有图片文件。

## 运行

依赖由仓库根目录统一管理，在根目录执行：

```powershell
pnpm install
pnpm dev:minecraft     # http://127.0.0.1:5176
pnpm build:minecraft   # 产出 我的世界/dist/
```

技术栈：Vite 8 + PlayCanvas 2.24 + Tailwind CSS v4。

## 操作

| 操作 | 按键 |
| :--- | :--- |
| 移动 | `W A S D` |
| 环顾 | 移动鼠标（点击画面锁定指针） |
| 跳跃 / 飞行时上升 | `Space` |
| 奔跑 / 飞行时下降 | `Shift` |
| 挖掉准星指向的方块 | 鼠标左键 |
| 放下当前方块 | 鼠标右键 |
| 吸取指向的方块 | 鼠标中键 |
| 切换快捷栏 | `1` - `9` / 滚轮 |
| 飞行模式开关 | `F` |
| 打开 / 关闭帮助 | `H` |
| 暂停并释放鼠标 | `Esc` |

进入水中会自动下沉，按住 `Space` 上浮。掉出世界底部会自动回到出生点。

## 世界里有什么

- **岛屿地形**：分形噪声生成丘陵、山脊与雪山，海平面以下是湖与海；世界边缘压回海面以下，配上延伸到地平线的远海平面，看起来就是一座漂在海上的岛。
- **十六种方块**：草、泥土、石头、圆石、沙、原木、树叶、木板、玻璃、砖、水、基岩、荧石、砂砾、雪，全部由 Canvas 逐像素画出 16×16 贴图后拼成图集。
- **橡树林**：按区块种子随机生长，树干 4–6 格，树冠两层。
- **第一人称物理**：重力、跳跃、逐轴 AABB 碰撞、贴地检测、游泳浮力。
- **挖掘与建造**：体素 DDA 射线拾取（最远 6 格），破坏 / 放置后只重建受影响的区块，选中方块带黑色描边。
- **天空**：渐变天球 + 缓慢飘动的云层，雾色与地平线对齐；潜入水下会切换成深蓝滤镜与短距离雾。

## 实现要点

- **区块与网格**：世界切成 10×10 个 16×16×64 的区块。每个区块只生成「露在外面」的面，相邻面按不透明 / 同种方块剔除，整片地形因此只需要一张图集材质。
- **烘焙顶点色**：方向明暗（顶 1.0、南北 0.9、东西 0.8、底 0.62）与环境光遮蔽（AO）直接写进顶点色，配合 `diffuseVertexColor` 与一盏方向光，得到干净的体素立体感；每块再加一点确定性色差，避免大片同色。
- **两套材质**：不透明地形一张，玻璃与水共用的半透明材质用图集的 alpha 通道作 `opacityMap`，`BLEND_NORMAL` + 不写深度。
- **程序化贴图**：`textures.js` 用 Canvas 逐像素画 16×16 图块再拼成 128×128 图集，`PIXELFORMAT_SRGBA8` + 最近邻过滤保持像素感。
- **性能**：区块按帧分摊构建，加载时每帧 2 个区块；运行期每帧最多重建 1 个脏区块。实测 100 个区块约 5 万三角形，桌面 60 fps。
- **PlayCanvas 用法**：引擎直连（`new Application(canvas, { mouse, keyboard })`），全部实体用 `addComponent('render', { meshInstances })` 手工组装，`Mesh.setPositions / setUvs / setColors / setIndices` 生成几何，`app.on('update', dt => …)` 驱动主循环。

## 已知限制

- 世界是固定大小的 160×160 格，不是无限区块流式加载；走到边界看到的是外海。
- 没有光照传播（火把照明、昼夜循环），荧石只是自发光材质。
- 没有生物、合成、背包与存档；刷新页面即重新生成世界。
- 需要键盘与鼠标，触屏设备只能看开始界面。
