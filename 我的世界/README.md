# 我的世界 · Mine World

用 **PlayCanvas 2.x** 复现的《我的世界》体素沙盒：一片程序化生成的方块岛屿，可以第一人称走过去、挖开它、造出工具、打退僵尸，再把它重新盖起来。地形、树木、方块贴图、物品图标、天空与云层全部在浏览器里实时生成 —— 没有 `.glb`、没有图片文件。

## 运行

依赖由仓库根目录统一管理，在根目录执行：

```powershell
pnpm install
pnpm dev:minecraft     # http://127.0.0.1:5176
pnpm build:minecraft   # 产出 我的世界/dist/
```

技术栈：Vite 8 + PlayCanvas 2.24 + Tailwind CSS v4。

## 操作

| 操作 | 按键 |
| :--- | :--- |
| 移动 | `W A S D` |
| 环顾 | 移动鼠标（点击画面锁定指针） |
| 跳跃 / 飞行时上升 | `Space` |
| 奔跑 / 飞行时下降 | `Shift` |
| 挖掘方块 / 攻击怪物 | 按住鼠标左键 |
| 放下当前方块 | 鼠标右键 |
| 从背包里选中指向的方块 | 鼠标中键 |
| 切换快捷栏 | `1` - `9` / 滚轮 |
| 打开 / 关闭背包与合成 | `E` |
| 飞行模式开关 | `F` |
| 打开 / 关闭帮助 | `H` |
| 暂停并释放鼠标 | `Esc` |

进入水中会自动下沉，按住 `Space` 上浮。掉出世界底部会自动回到出生点。

## 世界与玩法

### 地形与方块

- **岛屿地形**：分形噪声生成丘陵、山脊与雪山，海平面以下是湖与海；世界边缘压回海面以下，配上延伸到地平线的远海平面，看起来就是一座漂在海上的岛。
- **十九种方块**：草、泥土、石头、圆石、沙、原木、树叶、木板、玻璃、砖、水、基岩、荧石、砂砾、雪，外加煤矿石、铁矿石、钻石矿石。全部由 Canvas 逐像素画出 16×16 贴图后拼成图集。
- **矿脉**：煤矿石生成在 6–48 层、铁矿石 3–36 层、钻石矿石只出现在 1–16 层且非常稀少；矿脉用随机游走连成小团，只替换石头。
- **橡树林**：按区块种子随机生长，树干 4–6 格，树冠两层。

### 背包与合成

- **36 格背包**：前 9 格是快捷栏，后 27 格是储物格。物品按 64 个一堆叠放，工具与武器独占一格并带耐久条。
- **操作**：左键拿起 / 放下 / 交换，右键拿一半或放一个，`Shift + 左键`在快捷栏与储物格之间快速移动；关闭背包时手上拿着的东西会自动放回背包。
- **合成**：背包右侧是配方列表，材料够时点一下就合成 —— 原木 → 木板 → 木棍 → 工具 / 武器。配方按「木 / 石 / 铁 / 钻石」四档排列，材料不足时整行变暗并显示缺什么。
- **矿石直接出成品**：没有熔炉，铁矿石掉铁锭、钻石矿石掉钻石、煤矿石掉煤炭。

### 工具与武器

- **四类工具**：镐（挖石头与矿石）、斧（砍木头与树叶）、铲（挖土、沙、雪、砂砾）、剑（武器）。每类分木 / 石 / 铁 / 钻石四档。
- **挖掘规则**：硬度 × 是否用对工具 × 工具等级共同决定耗时 —— 木头镐挖石头 0.75 秒，空手要 3.3 秒；用错工具（拿镐铲土）会慢一倍多。
- **掉落门槛**：石头类需要木镐以上，铁矿石要石镐以上，钻石矿石要铁镐以上；等级不够能挖掉方块但不会掉落。
- **耐久**：每次成功挖掘（或剑命中）扣 1 点耐久，归零时工具损坏并提示。快捷栏与背包里都能看到耐久条，颜色随剩余量从绿变黄变红。
- **攻击**：剑 4–7 点伤害，斧 3–6，镐 2–5，铲 1–4，空手 1 点；有 0.42 秒攻击冷却，命中会击退。

### 僵尸与生命

- **方块僵尸**：用顶点色拼出的方块人形（头、身体、双臂前伸、双腿），会四处游荡；玩家进入 18 格范围就开始追击，贴身后每 1.7 秒造成 2 点伤害并击退。
- **生命值**：20 点（10 颗心），受伤后有 0.5 秒无敌帧，脱离战斗 6 秒后每 2.2 秒回 1 点；生命归零显示死亡界面，回到出生点满血复活，背包不掉落。
- **掉落**：僵尸必掉腐肉 1–2 个，30% 概率掉煤炭、12% 概率掉铁锭；每击杀一只回 1 点血。
- **数量**：世界里维持最多 4 只，离玩家 18–40 格处补刷。

### 交互与反馈

- 挖掘时准星下方显示进度条，方块被选中时有一圈黑色描边。
- 挖到东西、工具损坏、背包已满、合成成功都会在屏幕下方弹出提示。
- 受伤时屏幕边缘泛红；手持物品会显示在画面右下角，挥动时有摆动动画。

## 实现要点

- **区块与网格**：世界切成 10×10 个 16×16×64 的区块。每个区块只生成「露在外面」的面，相邻面按不透明 / 同种方块剔除，整片地形因此只需要一张图集材质。
- **烘焙顶点色**：方向明暗（顶 1.0、南北 0.9、东西 0.8、底 0.62）与环境光遮蔽（AO）直接写进顶点色，配合 `diffuseVertexColor` 与一盏方向光，得到干净的体素立体感；每块再加一点确定性色差，避免大片同色。
- **两套材质**：不透明地形一张，玻璃与水共用的半透明材质用图集的 alpha 通道作 `opacityMap`，`BLEND_NORMAL` + 不写深度。
- **程序化贴图**：`textures.js` 用 Canvas 逐像素画 16×16 图块再拼成 128×128 图集，`PIXELFORMAT_SRGBA8` + 最近邻过滤保持像素感。
- **程序化物品图标**：`icons.js` 在 16×16 像素网格上画工具 / 武器 / 材料，自动扫描透明边缘补一圈深色描边，再放大到 48×48；方块图标直接裁图集。图标同时用于快捷栏、背包、配方和手持 3D 贴片。
- **手持物品**：一张贴在相机前方的方片，用物品图标的 Canvas 当 `diffuseMap + opacityMap`，`alphaTest` 抠掉透明区域，挥动时做位移与欧拉角插值。
- **僵尸**：几何只算一次，每只怪物各建一个 `Mesh`（共享网格会被 `MeshInstance.destroy()` 连带销毁）；材质按怪物独立，受击时把 `diffuse` 调红。
- **性能**：区块按帧分摊构建，加载时每帧 2 个区块；运行期每帧最多重建 1 个脏区块。实测 100 个区块约 5 万三角形 + 4 只僵尸，桌面 60 fps。
- **PlayCanvas 用法**：引擎直连（`new Application(canvas, { mouse, keyboard })`），全部实体用 `addComponent('render', { meshInstances })` 手工组装，`Mesh.setPositions / setUvs / setColors / setIndices` 生成几何，`app.on('update', dt => …)` 驱动主循环。

## 已知限制

- 世界是固定大小的 160×160 格，不是无限区块流式加载；走到边界看到的是外海。
- 没有光照传播（火把照明、昼夜循环），荧石只是自发光材质。
- 只有僵尸一种怪物，没有动物、村民与 Boss；没有存档，刷新页面即重新生成世界。
- 合成走配方列表而不是 3×3 工作台；没有熔炉、箱子与附魔。
- 需要键盘与鼠标，触屏设备只能看开始界面。
