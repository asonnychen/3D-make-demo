# 太阳系概览 · Solar System

## 作品概述

一个用 Three.js 构建的可交互太阳系观察台。它不做天文计算，而是把「观察」本身做成产品：以像素月面开场，进入后可以在整个恒星系里自由旋转缩放，也可以一次只盯住一颗天体，用五种机位研究它的自转、倾角、昼夜与表面细节。

全部天体纹理都由 Canvas 逐像素生成，没有任何图片、模型或字体文件。

## 开场：像素月面

开场画面是一块 420×235（移动端 180×101）的低分辨率画布，放大后得到清晰的像素块：

- 星点、月海、约 90 个大小不一的撞击坑逐层绘制；
- 光来自左上，右下沉入黑暗，边缘留一圈极淡的环形亮边；
- 绘制完成后对月球区域做灰度量化（16 级台阶），把平滑的渐变压成像素色块；
- 标题 `SOLAR SYSTEM` 用自绘的 5×7 点阵字库渲染，不依赖外部字体。

点击、按 Enter 或空格进入主场景，遮罩淡出。

## 场景构成

**层级**：每颗行星是 `公转支点 → 位置锚点 → 轴倾角组 → 球体` 四层，月球挂在地球的位置锚点下。这样自转、公转、倾角互不干扰，月球也自然随地球移动。

**程序化表面**：

| 天体 | 生成方式 |
| :--- | :--- |
| 太阳 | 高频 fbm 米粒组织 + 脊状噪声 + 暗斑，`MeshBasicMaterial` 加两层辉光 Sprite，另有两层着色器火焰球壳 |
| 水星 / 月球 / 火星 | 岩石色带 + 低频月海 + Canvas 径向渐变撞击坑（跨经度接缝重复绘制） |
| 金星 / 木星 / 土星 / 天王星 / 海王星 | 纬度条带 + 噪声扰动的流场，木星外加大红斑 |
| 地球 | 同一高度场分出深海 / 浅海 / 海岸 / 内陆 / 高山，按纬度叠极冠 |
| 地球云层 | 独立的半透明球壳，比地表转得快一点 |
| 地球大气 | 菲涅尔着色器沿边缘叠加蓝色散射 |
| 土星环 | 一维环带纹理，片元按真实半径采样，含卡西尼缝等 4 条暗缝 |

**太阳火焰**：不用粒子，而是两层紧贴表面的球壳。顶点着色器用 3D 值噪声的 fbm 位移顶点，噪声随时间向上流动，于是球壳轮廓局部鼓起；片元只在临边（法线与视线夹角大）显示，亮度由另一组噪声决定，火焰因此沿轮廓断裂成断续的火舌，并带一层向外翻卷的更大起伏。加法混合、`depthWrite: false`，两次 draw call；暂停时时间停走，火焰凝固。

**潮汐锁定**：月球自转角度恒等于公转角 + π，因此总以同一面朝向地球，和真实一致。

## 观察与相机

- 选中天体后，相机目标点持续跟随它；半径、方位角、俯仰角各自缓动。
- 跟随使用两档阻尼：目标远时慢速飞行，接近后收紧阻尼，消除公转带来的滞后。
- 指针拖拽、双指捏合、滚轮会直接改写球坐标并「接管」，自动机位不会抢回控制权。
- 五种机位都相对太阳方向计算：
  - **受光面**：相机位于天体朝太阳的一侧；
  - **晨昏线**：与太阳方向垂直，看昼夜交界和地形阴影；
  - **极区**：高俯角看自转轴与极冠；
  - **夜侧**：太阳背面，只留环境光；
  - **细节**：贴近表面，看云、环缝或撞击坑。
- 竖屏会根据宽高比自动拉远距离，保证球体完整入画。

## 界面

黑白灰为主：像素点阵标题、等宽数字、细分隔线、半透明面板。界面中永不出现彩色强调色，颜色只属于天体本身。

- 左上：品牌与像素标题；右上：总览 / 天体 / 显示设置；
- 左侧：按恒星、行星、卫星分组的目录，编号 01–10；
- 左下：作品名、提示与当前序号；
- 底部：暂停、自转、公转、速度、轨道线、重置、前后切换；
- 选中后底部上方出现机位条；
- 右侧：介绍、关键数据、观察重点、资料来源与展示性调整说明；
- 键盘：方向键、空格、Esc、O/L、1–0；
- `prefers-reduced-motion`：默认暂停、缩短过渡、隐藏闪烁光标。

## 展示性调整

真实尺度在屏幕上无法同时成立：若按比例，地球在 1 AU 处只有几个像素，海王星则远到看不见。因此：

- 行星半径在 0.36–4.0 世界单位之间人工排布；
- 轨道半径按对数感受压缩到 6.6–37.6；
- 月球轨道压缩到 1.85，并放大月球半径；
- 自转、公转周期全部重新分配，保证一分钟内能看出运动。

信息面板里的直径、质量、距离与温度仍是真实数据，界面底部另有明确说明。

| `src/main.js` | 全局状态、选择逻辑、机位计算、渲染循环、UI 事件 |
