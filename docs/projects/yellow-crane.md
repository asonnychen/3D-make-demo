# 黄鹤楼 · Yellow Crane Tower

> Three.js · 程序化楼阁 · 第一/第三人称漫游 · 昼夜与 NPC

## 一句话

在浏览器里重建「江南三大名楼」之一的黄鹤楼：五层重檐、两层石台基、可走入的室内大厅、能一路爬到顶层的「之」字楼梯，以及从顶层望出去的长江、蛇山与武汉城市剪影。

## 画面与内容

### 建筑

- 总高约 51 米，五层楼阁，楼身逐层收分（半宽 10 m → 4.4 m）。
- 两层方形石台基：40 m × 1.6 m、32 m × 1.4 m，南侧两段石阶连接广场。
- 每层：红色檐柱、黄琉璃瓦屋面、四角起翘、檐下三层叠涩斗拱、外回廊与木栏杆。
- 顶部为攒尖顶，金色宝顶由多层球体、宝珠与尖刹组成，标高 45–51 m。
- 底层大厅围合：南侧正门、东侧花窗、北侧实墙、西侧实墙贴《白云黄鹤》壁画；门上方悬「黄鹤楼」金字匾额。

### 室内

- 底层大厅：程序化壁画（渐变天空、祥云、仙鹤、江面、远处楼阁剪影与题字）。
- 二至五层：开放大厅 + 主题陈列台，分别为青铜鼎、青花瓷瓶、楚式编钟、铜鹤；点击任意展品或壁画，用 `Raycaster` 弹出中文介绍卡片。
- 「之」字形木楼梯：每层两跑 + 休息平台，镂空踏步、斜梁、扶手与立柱，可实际行走上下。
- 楼板为楼梯预留洞口，洞口三面设护栏，第四面正对楼梯出口。

### 环境

- 蛇山地形：中心广场平台，向外以低频噪声起伏下降到江岸。
- 石阶广场、松树（树干 + 三层锥形树冠）、长江水面（Canvas 水纹 + 偏移动画）、对岸低多边形城市（窗灯在夜间点亮）。
- 渐变天空球（自定义 Shader）、缓慢漂移的云、夜间星空。
- 昼夜切换：天空、雾、太阳/半球光、星空、城市窗灯、室内点光源、灯笼自发光与泛光强度一起插值。

### 游客

- 5 个低多边形 NPC，随机衬衫/裤子/肤色/发型。
- 每层有漫步点（大厅 + 回廊），路线避开楼梯洞口；跨层时沿楼梯的显式路径点移动，能上能下。
- 到达目标后随机停留 1–4 秒并缓慢转头「看风景」。

## 交互

| 操作 | 桌面 | 手机 |
| :--- | :--- | :--- |
| 移动 | WASD / 方向键 | 虚拟摇杆 |
| 视角 | 鼠标拖拽 | 手指拖拽 |
| 跳跃 | 空格 | 「跳」按钮 |
| 第一/第三人称 | 按钮 / V | 按钮 |
| 飞行开关 | 按钮 / F | 按钮 |
| 飞行升降 | 空格上升 / Shift 下降 | 「升」/「降」按钮 |
| 昼夜 | 按钮 / N | 按钮 |
| 展品介绍 | 点击 | 轻点 |

第三人称会显示一个蓝色长衫的低多边形角色，并支持滚轮调整相机距离（2.6–9 m）。

飞行模式会关闭重力：空格持续上升、Shift 持续下降，移动速度提高到 9 m/s；飞行时不受建筑碰撞限制，便于从空中俯瞰楼体、蛇山与长江，但仍被限制在场景边界内且不会穿到地面以下。退出飞行后从当前高度自然下落。

## 实现要点

### 碰撞与可行走面

玩家是一个半径 0.32 m 的圆柱，竖直方向由重力与支撑面决定：

- **水平碰撞**：圆形 vs AABB，两轮迭代推出；碰撞盒带 `y0/y1`，只有与身体竖直范围重叠时才生效。
- **支撑面**：`getSupportY(x, z, refY)` 在「地形 + 楼板矩形 + 楼梯斜面 + 平台」中取不高于 `refY` 的最高面；上台阶时允许 0.55 m 的自动抬升。
- **防跌落**：回廊外栏杆、楼梯扶手、楼板洞口护栏、墙体都有碰撞盒；楼板在楼梯处被拆成 4 块矩形，形成真实洞口。
- **楼梯**：两跑分别登记为沿 X 的斜面，休息平台为矩形；踏步只是视觉几何，行走高度由斜面决定。

### 合批与性能

- `GeoBatch` 把同材质的小构件合并为一个 `BufferGeometry`：檐柱、斗拱、栏杆、踏步、楼梯斜梁、灯笼等各自成批。
- 屋面使用自定义网格（方形环面 / 攒尖面），四角起翘由 `lift * corner^3.2 * t^1.6` 控制。
- 阴影贴图 2048，单方向光投影；移动端像素比上限 1.6，竖屏 FOV 自动放大到 80°。
- 场景约 10 万三角形、~270 draw call，桌面独显可稳定 60 fps。

### 纹理

全部 Canvas 2D 绘制：

- 红漆木纹（立柱、栏杆、楼梯）
- 黄琉璃瓦（竖向瓦垄 + 横向接缝）
- 石材（错缝砖 + 噪点，灰度近中性避免彩斑）
- 深色木地板、天花藻井、米色墙面
- 《白云黄鹤》壁画（1024×512，含仙鹤路径绘制）
- 「黄鹤楼」匾额（1024×288）
- 江水、云、城市窗格

### 内存管理

`main.js` 的 `disposeAll()` 会：

1. `renderer.setAnimationLoop(null)`；
2. 移除键盘、指针、滚轮、按钮、摇杆、resize、beforeunload 监听；
3. `player.dispose()`（含第三人称角色）与 `npcs.dispose()`；
4. `composer.dispose()`；
5. 遍历场景释放几何体、材质与贴图；
6. `mats.dispose()`、`renderer.dispose()`、移除 canvas；
7. 删除调试用的 `window.__yc`。

`beforeunload` 与 Vite HMR 都会调用它。
