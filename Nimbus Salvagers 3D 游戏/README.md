# Nimbus Salvagers · 云海拾荒者

穿越漂浮遗迹的第一人称科幻远征。工程师 VELA-07 从 Cirrus Reach 涡轮机站点出发，追踪失落信号，抵御三波风之守卫，修复涡轮机，收集线圈代币。

第一人称武器带完整换弹动作：枪身倾斜、弹匣掉落、左手换匣、拉机柄复位；行走摆动、视线拖拽、后坐力、瞄准变焦与镜头震动一并实现。

全部场景、角色、敌人、云海与音效均在浏览器里实时程序化生成 —— 没有 `.glb`、没有贴图文件、没有音频文件。

## 运行

```powershell
cd "Nimbus Salvagers 3D 游戏"
pnpm install
pnpm dev      # http://127.0.0.1:5174
pnpm build    # 产出 dist/
pnpm preview  # 预览构建结果
```

技术栈：Vite 8 + Three.js r187 + Tailwind CSS v4。

## 玩法循环

1. **第一章 · 云海之上** —— 从拾荒者码头出发，跳过断桅岩与信标石，沿途收集线圈代币，抵达涡轮机竞技场。
2. **第二章 · 失落的信号** —— 在圆形甲板上抵御三波守卫：
   - 第一波：4 名巡弋守卫
   - 第二波：5 名巡弋守卫 + 1 名风帆枪手
   - 第三波：6 名巡弋守卫 + 1 名风帆枪手 + 1 名风帆守卫长
3. **第三章 · 风之核心** —— 清场后靠近控制台，按住 `E` 接入线圈，修复涡轮机，触发风之核心重启与结算。

### 成长与收藏

- **线圈代币**：12 枚固定收集品分布在踏脚石与外岛，敌人击坠时掉落，每清一波额外 +2。
- **自动改装**（按累计代币解锁）：
  - 8 枚：弹道增幅 · 伤害 +15%
  - 16 枚：扩容弹匣 · 弹匣 +12
  - 24 枚：脉冲循环 · 技能冷却 -30%
  - 32 枚：护甲强化 · 最大生命 +25
- **探索**：三座外岛（西侧残骸 / 东侧残骸 / 北侧风帆）需要跳跃或冲刺跨越，藏着额外代币。

### 生存规则

- 生命 100，脱离战斗 6 秒后缓慢恢复。
- 坠落云海会回到最近平台中心并损失 16 点生命。
- 阵亡后可从当前波次重试，保留已收集的代币与改装。

## 战斗系统

| 系统 | 说明 |
| :--- | :--- |
| 自动步枪 AR-9 | 30 发弹匣，9.5 发/秒，命中判定为射线 vs 敌人包围球，带曳光与枪口闪光 |
| 过载脉冲 | `Q` 释放半径 9.5 m 的能量冲击，70 伤害并击退，冷却 12 秒 |

| 敌人 AI | 环绕玩家保持距离、预测移动提前量射击、枪手三连发、守卫长周期性环形弹幕 |
| 受击反馈 | 屏幕红闪、镜头震动、命中标记、击坠爆炸、代币掉落 |
| 换弹动画 | 1.35 秒：枪身倾斜抬起、弹匣掉落（世界空间物理）、左手换匣、拉机柄复位；第一人称武器在独立场景中渲染，不受世界 FOV 拉伸 |

## 为后续模式预留

- **合作模式**：`EnemyManager` 与 `Player` 已按“多实例友好”拆分，敌人目标只依赖传入的 `player` 引用；HUD 的对白/技能条可复制为第二套。
- **风之试炼**：`WAVES` 是数据驱动的波次表，`startWave(index)` 可循环调用；`UPGRADE_TIERS` 可继续追加无尽成长档位。
- 标题界面与胜利界面已放置两张“待解锁”模式卡，接入时替换为可用入口即可。

## 视觉设计

- **云海**：程序化 fbm 噪声着色器平面 + 三层柔和云团精灵，随时间缓慢漂移。
- **帆状机械**：所有风帆由 `PlaneGeometry` 顶点鼓动生成，逐帧更新顶点模拟受风起伏。
- **蓝绿色能量**：涡轮机核心、甲板同心环、守卫核心、代币、技能脉冲统一使用 `#5eead4` 一族的自发光材质，配合 UnrealBloom 泛光。
- **漂浮遗迹**：锥形岩体 + 苔原顶面 + 断柱/拱门/系泊风帆，远处还有剪影浮岛与浮空碎石。
- **天空**：自定义渐变 + 太阳光晕着色器；暖色低角度阳光与冷色补光形成蓝绿 / 琥珀对比。

## 程序化音频

`src/audio.js` 使用 WebAudio 实时合成：

- 步枪：带通噪声扫频 + 低频冲击
- 命中 / 击坠 / 爆炸 / 冲刺 / 跳跃 / 拾取 / 改装
- 环境：风声噪声循环 + 低音铺底；修复后自动提亮滤波与音量

## 已知限制

- 仅支持键鼠；触屏设备会看到“需要键盘与鼠标”的提示。
- 指针锁定需要用户手势；浏览器拒绝时点击画面可重试。
- 低端集显建议降低窗口尺寸（渲染分辨率随 `devicePixelRatio` 自适应）。
