# Lac des Fleurs · 森林湖畔村庄

一片森林，中间有一座湖，湖心是一栋废弃宅邸，湖泊四周是一座繁花盛开的法国村庄。全部地形、房屋、树木、花朵、湖水与音效都在浏览器里实时程序化生成 —— 没有 `.glb`、没有贴图文件、没有音频文件。

支持两种视角：**俯瞰（Overview）** 环绕整座村庄，点击地点标记查看介绍并飞过去；**步行漫游（Explore on foot）** 以第一人称沿环湖道路走过广场、码头、薰衣草田与北岸凉亭。

## 运行

依赖由仓库根目录统一管理，在根目录执行：

```powershell
pnpm install
pnpm dev:village     # http://127.0.0.1:5175
pnpm build:village   # 产出 森林湖畔村庄/dist/
```

技术栈：Vite 8 + Three.js r187 + Tailwind CSS v4。

## 场景与地点

| 地点 | 说明 |
| :--- | :--- |
| 湖畔广场 · Place du Lac | 石砌喷泉、市集花摊、长椅与路灯；村庄道路的起点 |
| 西岸码头 · Le Vieux Quai | 木栈桥伸进湖里，可以走上栈桥和旁边的小船；站在船上按 `Space` 会开始 30 秒自动绕湖一周，期间只能转动视角 |
| 薰衣草田 · Champ de Lavande | 东岸的紫色花垄、蜂箱、矮石墙与木栅 |
| 废弃宅邸 · La Maison Oubliée | 湖心小岛上的三层石宅：塌掉一半的屋顶、空窗、木阳台、断木码头与半沉旧船 |
| 北岸凉亭 · La Pergola | 爬满蔷薇的木格架与长椅，正对湖心 |
| 林间步道 · Sentier des Bois | 从环湖路拐进密林的碎石小径与木路牌 |
| 圣米歇尔小教堂 | 广场南侧：钟楼、尖顶、十字架与玫瑰窗 |

所有地点由环湖路、支路与各家门前车道连接；湖心宅邸没有桥，只属于划船的人。

## 实现要点

- **地形**：统一高度函数 `groundHeight(x, z)` 生成湖盆、湖心岛与外围丘陵，路面、房屋、树木、花草全部共用，保证贴地。
- **湖水**：`Reflector` 平面镜面反射 + 自定义着色器做波纹扰动、菲涅尔、阳光碎金、岸边浅水与泡沫线。花朵、草叶、芦苇不参与倒影，节省大量三角形。
- **森林**：约 560 棵合并几何的树，用 `InstancedMesh` 渲染；顶点着色器注入风场，树冠随时间轻摆。灌木、花与草丛同样实例化。
- **村庄**：每栋房屋按材质合并成少量网格；屋顶、山墙、老虎窗、百叶窗、窗下花箱、门廊、烟囱与爬藤都由代码拼装。
- **程序化贴图**：草地细纹、碎石路、广场铺石、屋顶瓦片均由 Canvas 生成，无外部图片。
- **界面**：深林绿玻璃面板 + 奶油衬线标题；地点标记用 HTML 投影到 3D 坐标，点击后相机平滑飞行并弹出信息卡。
- **步行与碰撞**：WASD 移动、按住 Shift 奔跑、空格跳跃（重力与落地检测）；房屋与院墙使用旋转盒碰撞，树木、灌木、喷泉、长椅与摊位使用圆形碰撞，湖岸按水深限制，栈桥与小船有独立可行走面。
- **喷泉**：开口石砌水池、程序化涟漪水面、上层水碗与四条弧形水柱；水珠沿贝塞尔曲线循环落下。
- **湖上泛舟**：小船停靠在码头边，站上船按 `Space` 开始 30 秒一圈的自动航线；航行期间锁定移动、保留鼠标视角，结束时回到码头。
- **声音**：WebAudio 合成风声与偶发鸟鸣，首次进入步行模式时自动开启。

## 已知限制

- 步行模式需要键盘与鼠标；触屏设备可先使用俯瞰。
- 指针锁定需要用户手势；浏览器拒绝时点击画面可重新锁定。
- 湖心宅邸不可步行抵达（没有桥），这是场景设定。
- 乘船绕湖固定约 30 秒，航行期间不能移动或跳跃，只能转动视角。
- 湖面反射每帧渲染一次，低端集显建议缩小窗口（渲染分辨率已限制在 1.5 倍像素比）。
