# 电车街故事 · Tramline Stories (Port Morrow)

一个轻松治愈的海港小城自由驾驶与快递派送 3D 游戏。玩家在午后阳光明媚的 Port Morrow（莫罗港）开着心爱的「雨燕 N4 快递车（Kestrel N4 Courier）」，在旧电车轨道与海风拂面的街道中穿行，完成三个邻里差事，找回失踪邮包，修理与改装爱车，收听原创广播电台。

---

## 运行与控制

- **开发启动**：`pnpm dev:tramline`（本地端口 5182）
- **项目构建**：`pnpm build:tramline`（产物输出至 `电车街故事/dist`）
- **操作方式**：
  - `W / A / S / D` 或方向键：油门前进、刹车倒车、平顺转向
  - `SPACE`（空格）：手刹制动与侧身滑行漂移（地面胎痕与轮胎摩擦音）
  - `SHIFT`：氮气喷射加速（Nitro Boost），消耗氮气换取强劲推背感
  - `E`：自由上下车，切换驾驶与步行快递员探索模式；靠近目标时互动
  - `C`：切换 3 种镜头视角（第三人称追尾、驾驶舱第一人称、全景观光俯瞰）
  - `M`：展开 / 关闭水彩航海风莫罗港全景大地图（Full Map）
  - `ESC`：打开 / 关闭驾驶指南与帮助菜单
  - 点击右下角收音机：切换 3 大原创广播电台频道

## 核心实现要点

1. **城市与旧电车系统（City & Tram System）**：
   - 程序化生成莫罗港城市场景：沥青大道、双黄线、嵌入路面的旧电车铁轨系统、架空接触网电线与电线杆。
   - 自动巡游的老电车沿主轨道平稳往返行驶，并周期性发出逼真的电车铜钟敲鸣声。
   - 包含沿海防波堤海堤、海面波浪动态着色、Wharf 7 码头栈道、老渔船、北岬白色灯塔、钟楼大厦（Clockmarket）、Rue Prints 招牌街景与棕榈树、消防栓。

2. **雨燕 N4 快递车（Kestrel N4 Courier）与物理引擎**：
   - 忠实还原复古天青色方正车身、象牙白双层悬浮车顶、车顶实木行李架横条、车尾橙红拉环与方圆车灯。
   - 真实的悬挂俯仰与侧倾模拟，前轮转角与轮子自转同步。
   - 车辆耐久度系统（Health）：碰撞根据冲击速度扣除耐久，低耐久车头发烟降速，需在车库修复。
   - 漂移与刹车印系统：手刹漂移产生侧滑与沥青路面淡黑轮胎印，配合尖锐胎鸣音效。

3. **下车步行快递员模式（Courier Mode）**：
   - 按 `E` 键随时走下快递车，化身为头戴贝雷帽、身穿工装背心、背着牛皮纸邮包的可爱角色；
   - 可以在海港街道漫步、慢跑，深入车身无法驶入的隐秘角落探寻失踪邮包与街坊对话。

4. **三大邻里差事与失踪邮包探寻**：
   - **差事一：海滨烘焙坊的温热酸面包**（限时保温运送至北岬灯塔守塔人老汉斯）。
   - **差事二：旧电车机械所的急修轴承组**（码头 7 号栈道运载重型零件至旧电车维修间）。
   - **差事三：海港留声机黑胶唱片专递**（绝版爵士黑胶《莫罗港午后》送至钟楼咖啡馆）。
   - **失踪邮包搜集**：散布在小城 3 处的失踪包裹，拾取获得现金奖励，全集齐解锁荣誉勋章。

5. **莫罗修车库与个性化改装（Morrow Garage）**：
   - 一键维修恢复受损车况；
   - 6 款复古海港配色喷漆切换（海港天青、落日柑橘、薄荷牧草、午夜藏青、象牙白沙、邮政金辉）；
   - 三级引擎马力、三级悬挂调校、三级氮气系统升级，消耗现金提升整车性能。

6. **原创广播电台与 Web Audio 音频引擎**：
   - 原创 Web Audio API 合成三大电台频道：`海港频率 (Harbor Frequencies)`、`午后电车 (Tramline Afternoon)`、`潮汐微风 (Tidal Breeze)`；
   - 支持切台调频白噪音、拟真引擎轰鸣（根据转速平滑调制）、漂移胎鸣、撞击冲击、金币叮当声与海港海浪声。
