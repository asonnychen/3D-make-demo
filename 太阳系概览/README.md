# 太阳系概览 · Solar System

一个可交互的太阳系观察台。以像素月面开场，进入后可缩放拖动整个恒星系，点击任意天体把镜头平滑切到它身边，观察自转、公转、轴倾角、地球昼夜与云层大气、土星环和月面撞击坑。

所有星球表面都由 Canvas 程序化生成，没有任何外部贴图或模型。

## 运行

```powershell
# 仓库根目录
pnpm install
pnpm dev:solar      # http://localhost:5179

pnpm build:solar    # 输出到 太阳系概览/dist/
```

## 操作

| 操作 | 效果 |
| :--- | :--- |
| 开场点击 / Enter / 空格 | 从像素月面进入总览 |
| 拖拽 | 旋转镜头，随时接管自动机位 |
| 滚轮 / 双指捏合 | 缩放 |
| 点击天体、标签或左侧目录 | 选中并跟踪该天体 |
| ← / → | 上一颗 / 下一颗 |
| 1 – 0 | 直达编号对应的天体 |
| 空格 | 暂停 / 继续 |
| Esc | 关闭面板 → 返回总览 |
| O / L | 轨道线 / 天体标签 |
| R | 重置总览视角 |

底部控制条提供暂停、自转、公转、速度、轨道线、重置视角和前后切换；选中天体后底部上方会出现「受光面 / 晨昏线 / 极区 / 夜侧 / 细节」五个机位，也可以在「显示设置」里切换。

## 实现要点

- **太阳火焰**：两层球壳的顶点按 3D 噪声起伏，片元只保留临边的流动热浪，其中亮度由连续噪声决定，因此火焰会沿轮廓断裂成火舌；暂停时整层冻结。
- **程序化表面**：`paint()` 逐像素写入 `ImageData`，用可平铺的 fbm 噪声生成大陆、云带与气体行星条带；岩石天体再叠加 Canvas 绘制的陨石坑与月海。
- **地球**：水体 / 陆地 / 极冠按同一个高度场分色，云层是独立的半透明球壳，外层再用菲涅尔着色器画大气散射边缘。
- **土星环**：自定义 `ShaderMaterial` 按片元到中心的真实半径采样一维环带纹理，避免 UV 插值产生放射状条纹。
- **潮汐锁定**：月球自转角度直接等于公转角度 + π，永远同一面朝向地球。
- **相机**：相机目标点用两条阻尼曲线 —— 远距离平滑飞行、近距离收紧阻尼，从而消除跟随公转天体时的滞后；拖拽直接改球坐标，不被自动机位抢回。
- **展示性缩放**：行星半径与轨道半径都做了非线性压缩，自转与公转周期按可观察性重新排布；信息面板里同时给出真实数据。
- **可访问性**：全键盘可达、按钮使用 `aria-pressed`，窗口尺寸、触屏手势与 `prefers-reduced-motion` 都会改变相机距离、布局和默认动画状态。

## 已知限制

- 木星的四颗伽利略卫星、天王星与海王星的暗环未展开。
- 光照只用一盏无衰减点光源，没有行星互掩、环影、日食和真实星历。
- 程序化纹理每次启动重新生成，低端设备首次进入约需 1–3 秒。
- 距离、大小和公转速度均为展示性调整，不能用于天文计算。

## 项目提示词（Handoff）

> 在 `太阳系概览/` 目录内，用 Three.js + Vite + Tailwind CSS 4 制作一个可交互太阳系观察台。以低分辨率 Canvas 绘制的像素月面作开场，点击进入总览。
>
> 场景包含太阳、八大行星与月球：程序化生成全部表面纹理，实现自转、公转、轴倾角、太阳米粒组织与两层噪声位移的着色器火焰、地球昼夜与独立云层 + 大气散射、土星环（自定义着色器）、月球潮汐锁定与密集撞击坑。全部效果不用粒子。行星半径与轨道距离按非线性比例压缩，速度也做展示性调整，并在界面注明。
>
> 交互：点击天体 / 左侧目录 / 前后按钮切换，相机平滑跟踪目标且可随时拖拽接管；提供受光面、晨昏线、极区、夜侧、细节五种机位；暂停、速度滑块、自转、公转、轨道线、标签开关和重置视角。
>
> 信息面板展示中文介绍、真实数据、观察重点与 NASA 资料来源。界面黑白灰、像素标题（自绘 5×7 点阵字）、清晰正文，适配触屏、键盘与减少动态效果。端口 5179，输出 `dist/`。
