# 黄鹤楼 · Yellow Crane Tower

用 Three.js 程序化搭建的可漫游黄鹤楼：五层楼阁、两层石台基、外回廊、之字形楼梯、可进入的室内大厅与顶层远眺，配合蛇山、长江、武汉城市剪影与昼夜切换。

全部几何体与贴图均由代码实时生成，没有外部模型、图片或音频文件。

## 运行

依赖由仓库根目录统一管理，在仓库根目录执行：

```powershell
pnpm install
pnpm dev:yellowcrane     # http://127.0.0.1:5177
pnpm build:yellowcrane   # 构建到 黄鹤楼/dist/
```

`dist/` 已提交，可直接用静态服务器预览。

## 场景内容

- **楼体**：五层重檐楼阁，总高约 51 米；两层方形石台基（40 m / 32 m），南侧石阶连接广场；黄琉璃瓦屋面四角起翘，檐下三层斗拱；红色檐柱、外回廊与木质栏杆；顶部金色攒尖宝顶。
- **室内**：底层大厅四壁围合，西墙挂程序化绘制的《白云黄鹤》壁画（云纹、仙鹤、江面与楼阁剪影），正门上方悬「黄鹤楼」金字匾额；二至五层为开放大厅，各设主题陈列台（青铜鼎、青花瓷瓶、楚式编钟、铜鹤），可点击弹出中文介绍卡片。
- **楼梯**：每层一组「之」字形木楼梯（两跑 + 休息平台），镂空踏步、斜梁与红色扶手，可从底层一路走到顶层。
- **顶层**：四面敞开，可俯瞰长江水面、蛇山松林与对岸武汉城市剪影。
- **游客**：5 位低多边形 NPC 分别在各层漫步，会穿过大厅与回廊、上下楼梯，并偶尔停下「看风景」。
- **飞行模式**：按 `F` 或右上角按钮关闭重力，空格上升、`Shift` 下降，适合从空中俯瞰楼体与蛇山全景；飞行时不受建筑碰撞限制，但仍会被限制在场景范围内、不会钻到地面以下。退出飞行后从当前高度自然下落。
- **环境**：程序化蛇山地形、石阶广场、松树、带流动纹理的长江、对岸低多边形城市、渐变天空与漂移云朵；夜晚楼体灯光、灯笼、星空与泛光。

## 技术实现

- **程序化建模**：`src/tower.js` 用基础几何体拼装楼体，重复构件（檐柱、斗拱、栏杆、踏步等）通过 `GeoBatch` 合并，显著降低 draw call；屋面为自定义网格，四角起翘由参数化抬升实现。
- **程序化贴图**：`src/textures.js` 全部用 Canvas 2D 绘制（红漆木纹、黄琉璃瓦、石材、壁画、匾额、江水、云、城市窗格等）。
- **碰撞与行走**：`src/player.js` 使用圆形碰撞体对 AABB 列表求解；`src/tower.js` 同时输出「可站立面」列表（矩形、沿 X/Z 的斜面），`getSupportY` 负责台阶抬升、楼板与楼梯的落地判定。栏杆、墙体、楼梯扶手均有碰撞盒，楼板为楼梯预留洞口并在洞口设护栏。
- **NPC**：`src/npc.js` 为每层维护漫步点，楼梯使用显式路径点；跨层时先走到梯口，沿两跑楼梯逐点移动，再前往目标层漫步点；路线会避开楼梯洞口。
- **昼夜**：`src/environment.js` 与 `src/tower.js` 的 `setNight(k)` 统一插值天空、雾、光照、星空、城市窗灯、室内点光源与泛光强度。
- **后期**：`EffectComposer` + `UnrealBloomPass` + `OutputPass`，白天轻微泛光，夜晚增强。
- **性能**：阴影贴图 2048；移动端像素比上限 1.6；静态几何合批；材质与贴图统一登记并在卸载时释放。
- **内存管理**：`disposeAll()` 停止渲染循环、移除所有事件监听、释放 NPC / 玩家模型、后期处理、场景几何体与材质；HMR 与 `beforeunload` 均会触发。

## 已知限制

- 楼体比例经过艺术化压缩，便于在 51 米总高内布置五层可行走大厅；并非文物级测绘。
- NPC 不参与玩家碰撞，也不会彼此避让。
- 城市与对岸为低多边形远景，只保证登楼远眺时的剪影效果。
- 楼梯洞口附近的相机在第三人称下可能被栏杆短暂遮挡。
