# 3D 过山车游乐园 · Neon Circuit

一个完全程序化生成的三维过山车游乐园模拟器。玩家可以一键切换刺激轨道、实时拖拽编辑控制点、调整 banking（轨道侧倾角），并从四种视角体验列车运行。

## 运行方式

依赖由仓库根目录统一管理，本项目不单独安装依赖。

```powershell
# 在仓库根目录执行
pnpm dev:rollercoaster
# 打开 http://127.0.0.1:5178

pnpm build:rollercoaster
# 构建产物输出到本目录 dist/
```

## 操作

- `发车 / 暂停`：右下角按钮或空格键控制列车运行。
- 视角：左上角控制台切换第一人称、车尾跟随、站台仰视、自由鸟瞰。
- 轨道编辑：点击“编辑轨道”，控制球会出现在轨道上。
  - 拖动控制球：调整平面位置。
  - `Shift + 拖动`：调整控制点高度。
  - 鼠标滚轮或右侧滑块：调整该点的轨道侧倾角。
- `E`：切换编辑模式；`C`：循环切换视角；`N`：切换昼夜。
- 音效按钮开启程序化链条、风声与过弯摩擦声。

## 实现要点

- 轨道使用闭合 `CatmullRomCurve3`，通过平行传输标架保持方向连续，再叠加每个控制点的 banking 角。
- 竖直回环按真实圆弧密集采样，曲率恒为 1/R；圆弧内外补过渡点，使切线与相邻直线段自然衔接。
- 双轨、底部主梁、枕木与支撑立柱全部由轨道采样生成；枕木和立柱使用 `InstancedMesh`（实例化网格）降低绘制开销。
- 列车包含流线型车头与三节载客车厢，每节车厢独立采样轨道并平滑插值姿态，因此转弯时保持自然铰接。
- 物理速度按轨道切线方向积分重力、滚动摩擦（0.025 m/s²）与二次空气阻力（系数 0.0004）；链条段以 6.5 m/s 限速牵引，进站段按 `v² = 2as` 目标速度曲线模拟磁力刹车。速度允许为负，动力不足时会倒溜。
- 轨道几何遵循能量守恒：链条提升顶即全局最高点，俯冲把势能换成速度，其后的所有爬升都在可用动能之内，因此列车能稳定跑完一圈。
- G 值按乘客实际承受的法向合力计算（向心加速度 + 重力沿座椅法线分量），并做时间平滑，峰值落在真实过山车 4~6 G 区间。
- 昼夜环境、摩天轮彩灯、轨道霓虹灯带、车头聚光灯均由代码生成，没有外部模型、贴图或音频文件。

## 已知限制

- 轨道编辑仅改变当前预设，不提供新增或删除控制点。
- 移动端可操作完整界面，但精确拖拽控制点更适合触控笔或桌面鼠标。
- 第一人称过回环时采用四元数球面插值，避免欧拉角万向节死锁造成瞬间翻转。

## 项目提示词（Handoff）

请在 Three.js + Vite + Tailwind CSS v4 中复现一个程序化 3D 过山车游乐园。默认轨道必须使用闭合 `CatmullRomCurve3`，包含链条爬升、俯冲、360° 垂直回环、带 banking 的螺旋、波浪驼峰与进站制动段；竖直回环按真实圆弧密集采样（曲率恒为 1/R），圆弧内外补过渡点保证切线连续。双圆管轨道、底部主梁、枕木、立柱和回环 A 字架需根据轨道切线与侧倾标架实时生成。列车由流线型车头与三节载客车厢组成，每节车厢独立采样轨道并插值姿态，载客车上安排两名会举手摇晃的低多边形游客。物理系统按切线重力、摩擦和空气阻力积分速度，链条段牵引、进站段按 `v² = 2as` 磁刹，并允许动力不足时倒溜；轨道几何必须满足能量守恒（链条提升顶即全局最高点，俯冲换速度，其后爬升均在动能预算内），保证列车能完整跑完一圈。G 值按法向合力 `G = v²·(κ·up)/g + up.y` 计算，曲率用预计算 + 中值滤波 + 回环段解析曲率，避免数值尖峰。界面提供三套轨道预设、四种相机、实时侧倾编辑、时速/高度/G 值 HUD、昼夜切换与 Web Audio 程序化音效。场景需包含起伏草地、中央人工湖、旋转摩天轮、热气球、云朵和实例化松林。全部模型与音效必须程序化生成，不使用外部资源；阴影贴图不超过 2048，枕木与树木使用实例化渲染以保持流畅。
