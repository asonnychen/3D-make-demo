# 电车街故事 · Tramline Stories (Port Morrow)

一个轻松治愈的海港小城自由驾驶与快递派送 3D 游戏。玩家置身于阳光温暖的午后海港莫罗港（Port Morrow），驾驶经典的「雨燕 N4 快递车（Kestrel N4 Courier）」，在铺满旧电车轨道与海风拂面的街道中穿梭，完成三个邻里差事，找回散落小城的失踪邮包。

---

## 运行方式

在仓库根目录下执行：

```bash
# 启动开发服务器（端口 5182）
pnpm dev:tramline

# 构建生产产物（输出到 电车街故事/dist）
pnpm build:tramline
```

浏览器打开 `http://localhost:5182` 即可开始游玩。

## 操作说明

| 按键 | 功能 |
| :--- | :--- |
| `W` / `↑` | 油门加速（前进） |
| `S` / `↓` | 刹车制动 / 倒车 |
| `A` / `D` 或 `←` / `→` | 方向盘平滑转向（前轮联动偏转与车身侧倾） |
| `SPACE`（空格键） | 手刹制动 / 漂移甩尾（生成轮胎刹车印与尖啸声） |
| `SHIFT` | 氮气加速（Nitro Boost），消耗氮气产生推背冲刺与尾气火焰 |
| `E` | 上下车切换（自由切换驾驶模式与步行快递员探索模式）/ 交互 |
| `C` | 切换相机视角（第三人称追尾、驾驶舱第一人称、全景观光俯瞰） |
| `M` | 展开 / 收起莫罗港水彩航海风全景大地图（Full Map） |
| `ESC` | 打开 / 关闭帮助指南与操作说明面板 |
| 点击右下角收音机 | 切换 3 大原创原创广播电台频道（Lo-Fi、午后爵士、潮汐微风） |

## 游戏核心特色与玩法

1. **真实而优雅的驾驶手感与车辆物理**：
   - 完美还原低多边形复古天青色「雨燕 N4 快递车」：木质车顶行李架、方圆车灯与尾部挂钩。
   - 带有悬挂物理：加速抬头、刹车点头、急转侧倾，手刹漂移时轮胎打滑并在地面留下胎痕。
   - 车辆耐久度系统（Health）：碰撞障碍物会损耗耐久，耐久度过低时车头发烟降速，需在车库修复。
   - 氮气加速（Nitro）：自动缓慢恢复，高速冲刺带来强烈的视听冲击力。

2. **三个充满温情的邻里差事（Neighborhood Errands）**：
   - **差事一：海滨烘焙坊的温热酸面包**（限时保温送达北岬灯塔老守塔人汉斯大叔）。
   - **差事二：旧电车机械所的急修轴承组**（从海港 7 号栈道运送重型锻钢齿轮至调车场，鸣笛致谢）。
   - **差事三：海港留声机黑胶唱片专递**（将绝版爵士黑胶《莫罗港午后》送至钟楼咖啡馆）。

3. **主线探索：寻回 3 个失踪的失落邮包（Lost Parcels）**：
   - 散落在防波堤木船旁、旧电车支线长椅边与北岬山崖露台。
   - 拾取可获得丰厚现金奖励（+$2,000 / 个），全集齐荣获「金牌海港快递员」称号！

4. **莫罗修车库与改装展厅（Morrow Garage）**：
   - 一键修理恢复车辆耐久；
   - 6 款复古海港车身喷漆切换（海港天青、落日柑橘、薄荷牧草、午夜藏青、象牙白沙、邮政金辉）；
   - 三大性能升级：发动机马力（提高极速）、悬挂调校（增强抓地力）、氮气罐扩容（加快回充）。

5. **原创广播电台与 Web Audio 拟真音效**：
   - 原创 Web Audio API 合成三大电台频道：`海港频率 (Harbor Frequencies)`、`午后电车 (Tramline Afternoon)`、`潮汐微风 (Tidal Breeze)`，并模拟真实电台切台调频杂音；
   - 动态引擎轰鸣、手刹尖啸、碰撞冲击、电车清脆敲钟、金币进账与海浪海鸥白噪音。

6. **徒步探索模式（Courier Mode）**：
   - 随时按 `E` 键走下快递车，以第三人称操控戴着贝雷帽与邮差包的快递员角色步行探索海港窄巷与栈道，再按 `E` 登车。

## 项目提示词（Handoff）

```markdown
# 电车街故事 · 项目提示词 (Handoff Prompt)

## 项目背景
这是一个基于 Three.js + Tailwind CSS 的独立低多边形复古海港小城自由驾驶与快递派送 3D 游戏。
作品定位在暖金午后的海港小镇 Port Morrow（莫罗港），玩家驾驶天青色快递车 Kestrel N4 Courier，穿行于旧电车轨道和海滨街区之间。

## 运行与构建
- 端口：5182（`pnpm dev:tramline`）
- 打包：`pnpm build:tramline`（产物输出至 `电车街故事/dist`）
- 规范：单目录独立项目，共享根依赖，纯程序化 3D 建模无外部外部模型与音频资产依赖。

## 核心架构
- `src/audio.js`：无外部依赖的 Web Audio API 合成器，包含三大原创 Lo-Fi/爵士电台及汽车引擎、漂移、碰撞音效。
- `src/city.js`：程序化构建海港城镇、沥青主干道、双黄线、嵌入式旧电车铁轨、自动巡游老电车、海港海堤栈道与地标。
- `src/vehicle.js`：复刻原图方形经典快递车外观（木质车顶行李架、双层白顶、拉环），真实悬挂物理、手刹漂移、氮气冲刺与耐久度。
- `src/player.js`：支持 E 键上下车，下车切换为步行快递员进行漫步探索与近身拾取。
- `src/missions.js`：3 个邻里差事与 3 个失踪邮包的搜集逻辑与现金奖励。
- `src/main.js`：主循环、三重视角切换、雷达小地图实时 Canvas 绘制与全城水彩大地图。

## 维护与扩展建议
- 可在 `city.js` 中增加更多分支街道与海岛跨海大桥；
- 可在 `audio.js` 中通过 Web Audio 振荡器进一步扩展更多电台频道；
- 可在 `vehicle.js` 中增加更多车型解锁（如老式轻便小卡车、双层巴士）。
```
