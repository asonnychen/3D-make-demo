# 3D 过山车游乐园 · Neon Circuit

## 作品概述

`Neon Circuit` 是一款完全由代码生成的三维过山车游乐园模拟器。核心不是预设动画，而是可编辑的闭合样条轨道、基于重力积分的列车运动，以及围绕轨道连续生成的结构系统。

## 轨道系统

默认「经典大回环」预设依次包含：

1. 站台与检票护栏；
2. 恒速链条爬升；
3. 高空俯冲与湖面掠行；
4. 360° 垂直大回环；
5. 最高约 65° 的高速侧倾螺旋；
6. 连续波浪驼峰；
7. 磁力刹车进站段。

轨道由闭合 `CatmullRomCurve3` 生成。程序沿曲线计算切线，并用平行传输法维护连续标架；每个控制点再提供独立的 banking（轨道侧倾角）。该组合避免了普通 Frenet 标架在垂直回环附近的突然翻转，也能让轨道、枕木和支架始终共享同一方向。

竖直回环不依赖样条插值：程序按真实圆弧密集采样（经典 8m、峡谷 9m 半径），使曲率恒为 `1/R`；圆弧内外各补一个过渡点，保证切线与相邻直线段自然衔接。这样回环既是标准几何形状，G 值也能精确计算。

## 精细结构

- 左右两根不同颜色的圆管主轨；
- 轨道底部的粗主梁；
- 沿曲线等距采样、按轨道切线与侧倾方向摆放的金属枕木；
- 从轨道底部垂直落到地面的实例化钢结构立柱；
- 湖面区域内立柱继续延伸至水底；
- 大回环区使用双斜撑组成 A 字加固架；
- 起点与终点具备站台、遮阳棚、立柱和多重检票护栏。

## 列车与物理

列车由一个流线型导流罩车头与三节载客车厢组成。每节车厢独立采样轨道并对位置、朝向做阻尼插值，因此经过回环和急弯时不会出现刚性连接造成的穿模。

自由滑行速度按以下关系积分：

- 轨道切线方向的重力分量；
- 滚动摩擦（0.025 m/s²）；
- 与速度平方相关的空气阻力（系数 0.0004）；
- 链条段的限速牵引（6.5 m/s）；
- 进站段基于剩余距离的磁力制动曲线（`v² = 2as`）。

速度允许为负，因此在上坡动力不足时，列车会真实减速甚至倒溜。仪表盘的 G 值按乘客实际承受的法向合力计算（向心加速度 + 重力沿座椅法线分量），曲率向量由轨道系统预计算（中值滤波 + 回环段解析曲率），避免数值微分产生虚高尖峰。

### 能量守恒设计

三套预设的高度剖面经过能量预算核算：**链条提升段终点即全局最高点**，俯冲把势能换成速度，其后的所有爬升都落在可用动能之内。否则列车会在到达螺旋段或回环顶之前耗尽速度而回落。实测三套轨道均可稳定跑完一圈，爬坡段最低速保持在 20 km/h 以上，全程无倒溜。

## 交互与视听

- 三套预设：经典大回环、峡谷螺旋王、魔鬼双环；
- 四种相机：第一人称、弹簧延迟车尾跟随、站台仰视、自由鸟瞰；
- 编辑模式显示 3D 控制球，可拖拽位置、高度与侧倾角；
- Web Audio API 生成链条咔哒、动态风噪与过弯摩擦声；
- 白天使用渐变晴空、漂浮云朵和太阳阴影，夜晚启用轨道霓虹、摩天轮彩灯与车头聚光灯。

## 技术实现

| 模块 | 实现 |
| :--- | :--- |
| 轨道 | `CatmullRomCurve3`、平行传输标架、逐点 banking、圆弧段解析曲率 |
| 几何 | `TubeGeometry`、`InstancedMesh`、程序化低多边形角色与景物 |
| 物理 | 半隐式速度积分、重力/摩擦/阻力、制动目标速度、能量守恒高度剖面 |
| 相机 | 四元数 `slerp`（球面插值）、弹簧阻尼、`OrbitControls` |
| 音频 | Web Audio API 振荡器、滤波噪声与动态增益 |
| 渲染 | 2048 阴影贴图、实例化几何、像素比上限 1.75 |

所有模型、材质、天空与音效均为程序化生成，项目不依赖外部模型、图片或音频文件。
